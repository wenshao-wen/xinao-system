【C++ 23课---运算符号折扣率】🌈🌈 本节课重难点来了🌻🌻 ✅ 多分支语句练习，能够使用编程的知识点，做出计算器的效果 📝。 ✅ 折扣的计算，了解打折的概念，同时能够实现折扣的计算，多分支满减计算 📝 ✅ 百分数转小数的数学了解 📝 💖 课堂表现评价 💖 本节课孩子们整体表现优秀！大部分孩子能够理解折扣计算的数学逻辑，并尝试用多分支语句实现计算器和满减功能。在百分数转小数的基础运算上掌握较好，但部分孩子在多分支条件的边界判断上还需要加强练习。 📚📚 重要的知识点梳理（详细版） 📚📚 ✅① 变量的创建与数据类型选择 ✅ - 核心原则：根据数据特点选择对应类型，避免计算误差 - 整数类型（int）：适用于数量、金额整数部分（如：购买数量10件、满减门槛200元） - 浮点类型（double/float）：适用于价格、折扣率等带小数的场景（如：单价99.9元、折扣率0.85） - 错误示例：用int存储8.8折（0.88）会直接丢失小数部分，导致计算错误 - 正确示例： int count = 5; // 购买数量（整数） double price = 99.9; // 商品单价（小数） double discount = 0.8; // 折扣率（小数） ✅② 多分支语句的选择（if - else if - else 完整模型） ✅ - 执行逻辑：从上到下依次判断条件，满足第一个条件后执行对应代码，后续条件不再判断 - 结构说明： if(条件1) { // 条件1满足时执行 } else if(条件2) { // 条件1不满足、条件2满足时执行 } else if(条件3) { // 条件1、2都不满足、条件3满足时执行 } else { // 所有条件都不满足时执行（兜底逻辑） } - 注意事项：条件判断要注意顺序（范围小的条件放前面），避免逻辑覆盖 ✅③ 折扣率计算（核心知识点） ✅ - 基础概念： - 打几折 = 原价 × 折扣率（如：8折 = ×0.8，95折 = ×0.95） - 百分数转小数：折扣率 = 折数 ÷ 10（如：8折 = 8÷10=0.8） - 满减计算：最终价格 = 折扣后价格 - 满减金额（需满足满减条件） - 计算公式： - 折扣后价格 = 原价 × 折扣率 - 满减后价格 = max(折扣后价格 - 满减金额, 0) // 避免价格为负数 - 示例：原价299元，打8折后满200减30 折扣后：299 × 0.8 = 239.2元 满减后：239.2 - 30 = 209.2元 📖 核心知识点总结 & 实战案例解析 📖 🔹 实战案例1：基础折扣计算器 【需求】输入商品原价和折扣数（如8表示8折），计算折后价格 【完整代码】 #include using namespace std; int main() { // 1. 定义变量（注意数据类型选择） double original_price; // 原价（小数） int discount_num; // 折扣数（整数，如8表示8折） double final_price; // 折后价格（小数） // 2. 输入数据 cout << "请输入商品原价（元）："; cin >> original_price; cout << "请输入折扣数（如8表示8折）："; cin >> discount_num; // 3. 计算折扣率和折后价格 double discount_rate = discount_num / 10.0; // 百分数转小数（必须用10.0而非10） final_price = original_price * discount_rate; // 4. 输出结果 cout << discount_num << "折后的价格为：" << final_price << "元" << endl; return 0; } 【关键说明】 - discount_num / 10.0 而非 10：避免整数除法（8/10=0，8/10.0=0.8） - double类型存储价格：保证小数精度 🔹 实战案例2：多分支满减折扣计算 【需求】商场促销规则： - 消费满500元：打7折 - 消费满300元：打8折 - 消费满200元：打9折 - 其他：不打折但满100减10 【完整代码】 #include using namespace std; int main() { double total_price; // 消费总额 double pay_price; // 实际支付金额 cout << "请输入消费总额（元）："; cin >> total_price; // 多分支条件判断（注意条件顺序：从高门槛到低门槛） if(total_price >= 500) { pay_price = total_price * 0.7; cout << "满足满500打7折，实际支付：" << pay_price << "元" << endl; } else if(total_price >= 300) { pay_price = total_price * 0.8; cout << "满足满300打8折，实际支付：" << pay_price << "元" << endl; } else if(total_price >= 200) { pay_price = total_price * 0.9; cout << "满足满200打9折，实际支付：" << pay_price << "元" << endl; } else { // 兜底逻辑：满100减10 if(total_price >= 100) { pay_price = total_price - 10; cout << "满足满100减10，实际支付：" << pay_price << "元" << endl; } else { pay_price = total_price; cout << "无优惠，实际支付：" << pay_price << "元" << endl; } } return 0; } 【关键说明】 - 条件顺序：必须从高门槛（500）到低门槛（200），否则会出现逻辑错误 - 分支嵌套：else中嵌套满100减10的判断，实现更复杂的优惠规则 - 边界值处理：>= 包含等于的情况，符合实际促销规则 🔹 常见错误与bug排查 1. 数据类型错误：用int存储小数导致精度丢失 ❌ 错误：int price = 99.9; // 实际存储为99 ✅ 正确：double price = 99.9; 2. 整数除法错误：折扣率计算时用10而非10.0 ❌ 错误：double rate = 8 / 10; // 结果为0 ✅ 正确：double rate = 8 / 10.0; // 结果为0.8 3. 多分支条件顺序错误：低门槛放前面导致高门槛条件失效 ❌ 错误：先判断>=200，再判断>=500（500也满足>=200，会执行错误分支） ✅ 正确：先判断高门槛，再判断低门槛 作业练习网址：[点击这里](https://code.xdf.cn/freecode/editor?type=3&org=code)
