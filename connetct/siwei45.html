【C++---45 数组2】🌈🌈 本节课重难点来了🌻🌻 ✅ 数组概念（同种类型的多个数值的集合）📝 ✅ 数组的创建（数组的初始化方式）📝 ✅ 数组的访问（通过下标来访问数组元素）📝 📚📚 重要的知识点梳理 📚📚 ✅① 查询数组中某个具体数值（创建数组、保存数值、访问数组、逐一比较） ✅ ✅② 数组元素求和 （创建数组、保存数值、创建求和变量、访问数组、累加求和）✅ ✅③ 统计数组中某个数值的个数 （创建数组、保存数值、创建计数变量、访问数组、判断求和）✅ 💖 课堂表现评价 💖 本节课是数组的应用进阶，孩子们表现出色！能熟练回顾数组的概念、创建和下标访问等基础知识点，快速进入实战应用。在查询具体数值、元素求和、统计数值个数三大核心任务中，大部分孩子能梳理出"创建数组→存储数据→循环处理→输出结果"的完整流程，灵活运用循环遍历数组和分支判断逻辑，课堂练习的准确率很高，批量数据处理能力显著提升～ 📖 核心知识点总结（数组三大应用实战） 📖 🔹 一、数组基础回顾（核心前提） 1. 概念：存储同种类型多个数值的有序集合，如同"统一规格的储物格" 2. 创建格式：数据类型 数组名[长度];（如int arr[10]; 存储10个整数） 3. 访问方式：数组名[下标]（下标从0开始，范围0~长度-1） 4. 初始化方式：支持完全初始化、部分初始化、省略长度初始化（如int arr[]={1,2,3};） 🔹 二、数组三大核心应用（含完整思路+代码模板） 1. 应用1：查询数组中某个具体数值（判断目标值是否存在） - 核心需求：给定目标值，检查数组中是否包含该数值，输出是否存在及对应下标 - 实现步骤： ① 创建并初始化数组（或动态输入数组元素） ② 定义目标值target（如int target=5;） ③ 定义标记变量found=0（0表示未找到，1表示找到） ④ 循环遍历数组（for(int i=0; i<长度; i++)） ⑤ 逐一比较：if(arr[i] == target) → 标记found=1，输出"找到，下标为i" ⑥ 循环结束后：if(found==0) → 输出"未找到" - 代码模板： int arr[] = {2,5,8,3,10}; int len = sizeof(arr)/sizeof(arr[0]); // 计算数组长度 int target = 8; int found = 0; for(int i=0; i~len; i++){ if(arr[i] == target){ cout << "找到目标值" << target << "，下标为" << i << endl; found = 1; break; // 找到后可终止循环（可选） } } if(found == 0) cout << "未找到目标值" << target << endl; 2. 应用2：数组元素求和（计算所有元素的总和） - 核心需求：计算数组中所有元素的累加和 - 实现步骤： ① 创建并初始化数组（或动态输入） ② 定义求和变量sum=0（必须初始化为0，避免垃圾值影响结果） ③ 循环遍历数组，累加求和：sum += arr[i]（等同于sum = sum + arr[i]） ④ 循环结束后，输出sum即为总和 - 代码模板： int arr[] = {1,3,5,7,9}; int len = sizeof(arr)/sizeof(arr[0]); int sum = 0; for(int i=0; i~len; i++){ sum += arr[i]; } cout << "数组元素总和为：" << sum << endl; // 结果：25 3. 应用3：统计数组中某个数值的个数（计数目标值出现次数） - 核心需求：给定目标值，统计其在数组中出现的总次数 - 实现步骤： ① 创建并初始化数组（或动态输入） ② 定义目标值target和计数变量count=0（初始化为0） ③ 循环遍历数组，判断：if(arr[i] == target) → count++ ④ 循环结束后，输出count即为出现次数 - 代码模板： int arr[] = {3,5,3,7,3,9,5}; int len = sizeof(arr)/sizeof(arr[0]); int target = 3; int count = 0; for(int i=0; i~len; i++){ if(arr[i] == target){ count++; } } cout << "目标值" << target << "出现的次数为：" << count << endl; // 结果：3 🔹 三、关键注意事项 1. 变量初始化：求和变量sum、计数变量count必须初始化为0，标记变量found初始化为0 2. 数组长度：动态计算长度用sizeof(arr)/sizeof(arr[0])，避免硬编码（适配不同长度数组） 3. 循环边界：下标范围严格控制在0~len-1，避免下标越界 4. 效率优化：查询时找到目标值后可加break终止循环，减少无效遍历 作业练习网址： https://code.xdf.cn/freeIde?type=1（或者离线版DEV-C++） 完成后发班级群打卡
