【C++---42 枚举算法】🌈🌈 本节课重难点来了🌻🌻 ✅ 枚举的特点（有穷性、确定性、唯一性） 📝 ✅ 公因数（一个数既是a的因数又是b的因数，我们称这个数是a和b的公因数） 📝 ✅ 公倍数（一个数既是a的整倍数又是b的整倍数，我们称这个数是a和b的公倍数） 📝 📚📚 重要的知识点梳理 📚📚 ✅① 枚举算法核心思想：列举所有的可能结果，逐一进行验证 ✅ ✅② 百钱买百鸡（三层循环枚举公鸡、母鸡、小鸡购买的数量） ✅ ✅③ 鸡兔同笼（两层循环枚举小鸡的数量、兔子的数量） ✅ 💖 课堂表现评价 💖 本节课孩子们对枚举算法的学习表现积极！能快速理解枚举算法"列举所有可能、逐一验证"的核心思想，牢记"有穷性、确定性、唯一性"三大特点，也能清晰区分公因数和公倍数的概念。在经典案例练习中，大部分孩子能梳理出百钱买百鸡的三层循环逻辑和鸡兔同笼的两层循环逻辑，课堂上主动尝试优化循环范围，减少枚举次数，逻辑思维和动手实践能力都有明显提升～ 📖 核心知识点总结 📖 🔹 一、枚举算法基础 1. 三大核心特点： - 有穷性：枚举的可能结果是有限的，不能无限列举（如鸡兔同笼中头数固定，数量有上限） - 确定性：每个列举的结果都是明确的，无模糊或不确定的情况（如公鸡数量只能是0、1、2...） - 唯一性：每个可能的结果只列举一次，不重复枚举 2. 核心思想：将问题的所有可能解一一列举出来，代入问题的条件中验证，符合条件的就是有效解 3. 适用场景：问题的可能解数量有限、无法找到更高效算法时（如百钱买百鸡、鸡兔同笼等经典数学问题） 4. 公因数与公倍数（枚举算法应用基础）： - 公因数定义：一个数既是a的因数，又是b的因数，即为a和b的公因数（如6和9的公因数有1、3） - 公倍数定义：一个数既是a的整倍数，又是b的整倍数，即为a和b的公倍数（如4和6的公倍数有12、24、36...） - 枚举求法： - 公因数：枚举1到min(a,b)的所有整数，判断是否能同时整除a和b - 公倍数：枚举a的倍数（a、2a、3a...），判断是否也是b的倍数，直到找到目标公倍数 🔹 二、经典案例枚举思路（重点） 1. 百钱买百鸡（假设公鸡5钱1只，母鸡3钱1只，3只小鸡1钱，用100钱买100只鸡） - 问题分析：设公鸡x只、母鸡y只、小鸡z只，需满足两个条件： ① x + y + z = 100（总只数100） ② 5x + 3y + z/3 = 100（总钱数100，z必须是3的倍数） - 枚举思路（三层循环）： - 第一层循环（x）：x的范围0~20（5×20=100，最多买20只公鸡） - 第二层循环（y）：y的范围0~33（3×33=99，最多买33只母鸡） - 第三层循环（z）：z=100-x-y（由总只数条件推导，无需枚举所有，优化效率） - 验证条件：z是3的倍数，且总钱数满足5x+3y+z/3=100 - 核心优化：通过总只数公式推导z，减少一层循环，提升枚举效率 2. 鸡兔同笼（假设鸡和兔共35个头，94只脚，求鸡和兔各有多少只） - 问题分析：设鸡x只、兔y只，需满足两个条件： ① x + y = 35（总头数35） ② 2x + 4y = 94（总脚数94，鸡2只脚，兔4只脚） - 枚举思路（两层循环/优化为一层）： - 方法一（两层循环）： - 第一层循环（x）：x范围0~35（鸡的数量最多35只） - 第二层循环（y）：y范围0~35（兔的数量最多35只） - 验证条件：x+y=35且2x+4y=94 - 方法二（一层循环，优化）： - 循环x（0~35），y=35-x（由总头数推导） - 验证条件：2x+4y=94，符合则为有效解 - 核心优化：利用问题的约束条件减少循环层数，降低枚举次数，提升效率 作业练习网址： https://code.xdf.cn/freeIde?type=1（或者离线版DEV-C++） 完成后发班级群打卡
