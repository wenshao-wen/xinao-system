【C++---21课学校考试了】🌈🌈 本节课重难点来了🌻🌻 ✅ 逻辑运算与或非 📝。 ✅ 数学公式 ： 数量 = 总价 / 单价 掌握和计算方法 📝 ✅ 多分支判断语句 📝 💖 课堂表现评价 💖 本节课孩子们整体表现非常出色！大部分孩子上课专注认真，积极参与逻辑运算、数学公式应用、多分支语句等核心知识点学习，能熟练掌握逻辑运算"与或非"的使用场景，精准理解"数量=总价/单价"的数学公式及计算方法，还能结合多分支判断语句解决实际编程问题，独立解题能力显著提升。 📚📚 重要的知识点梳理 📚📚 ✅① 与： 多个条件都满足，条件成立 ，2位数的判断，最小的2位数10，最大的2位数99， 双分支语句判断 ✅ ✅② 或： 多个条件满足其中一个，条件成立， ✅ ✅③ 分支和字符类型，整数类型的输入判断， ✅ 📖 核心知识点总结 & CSP竞赛习题本采购问题解题思路 📖 🔹 两位数判断解题思路（逻辑与+双分支）： - 核心逻辑：if(num >= 10 && num <= 99) → 是两位数（逻辑与：同时满足≥10和≤99） - 双分支实现： if(num >= 10 && num <= 99) { cout << "是两位数"; } else { cout << "不是两位数"; } 🔹 CSP竞赛习题本采购问题完整解题思路： 【题目描述】：老师买n个习题本，有3种包装（数量/价格不同），只能买同一种且不拆包，求买够至少n个的最小花费。 【解题步骤】： 1. 输入准备： - 输入需要的总数量n - 输入3种包装的信息：包装1（数量a1，价格p1）、包装2（数量a2，价格p2）、包装3（数量a3，价格p3） 2. 单种包装花费计算（核心：向上取整）： - 包装1需要购买的包数： if(n % a1 == 0) → 包数 = n / a1 （刚好整除） else → 包数 = n / a1 + 1 （不能整除，需要多买1包） - 包装1总花费：cost1 = 包数 × p1 - 同理计算包装2总花费cost2、包装3总花费cost3 3. 最小花费判断（多分支/比较）： - 先比较cost1和cost2，找出较小值min_cost - 再比较min_cost和cost3，最终得到最小花费 - 或用多分支语句实现： if(cost1 <= cost2 && cost1 <= cost3) → 最小花费是cost1 else if(cost2 <= cost1 && cost2 <= cost3) → 最小花费是cost2 else → 最小花费是cost3 4. 关键知识点应用： - 逻辑与（&&）：用于多条件比较（如判断最小值） - 数学公式：总价=数量×单价（反向应用：数量=总价/单价） - 多分支语句：用于三种包装花费的最小值判断 - 整数判断：输入的n、包装数量/价格均为整数类型，需做输入合法性判断 🔹 输入类型判断技巧： - 整数类型判断：通过输入验证确保输入的是数字而非字符 - 字符类型判断：if(ch < '0' || ch > '9') → 不是数字字符 作业练习网址： https://code.xdf.cn/freecode/editor?type=3&org=code
