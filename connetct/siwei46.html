进制转换示例详解

🔢 二进制转十进制示例：二进制1101 → 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8+4+0+1 = 13

🔢 八进制转十进制示例：八进制157 → 1×8² + 5×8¹ + 7×8⁰ = 64+40+7 = 111

🔢 十六进制转十进制示例：十六进制2A → 2×16¹ + 10×16⁰ = 32+10 = 42

🔄 程序实现思路：从右到左遍历每一位，权值从1开始每次乘以进制数，将数码与权值相乘后累加
