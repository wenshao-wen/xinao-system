【C++---44 一维数组】🌈🌈 本节课重难点来了🌻🌻 ✅ 数组概念（同种类型的多个数值的集合）📝 ✅ 数组的创建（数组的初始化方式）📝 ✅ 数组的访问（通过下标来访问数组元素）📝 📚📚 重要的知识点梳理 📚📚 ✅① 数组一旦创建，长度就是确定的 ✅ ✅② 数组下标的范围（从0开始到数组的长度-1） ✅ ✅③ 掌握数组使用的基本模板（输入数据长度、创建数组、动态输入、动态输出）✅ 💖 课堂表现评价 💖 本节课孩子们对一维数组的学习接受度很高！能快速理解数组"存储同种类型多个数据"的核心概念，熟练掌握数组的创建和初始化方法，也能通过下标正确访问数组元素。在数组使用模板的练习中，大部分孩子能按"输入长度→创建数组→动态输入数据→动态输出数据"的步骤编写代码，理解数组长度固定、下标从0开始的关键规则，课堂互动积极，对批量数据处理的编程思维有了初步建立～ 📖 核心知识点总结 📖 🔹 一、一维数组核心概念 1. 定义：数组是存储**同种数据类型**多个数值的集合，相当于"多个同类型变量的有序容器" - 示例：存储5个学生的成绩，用数组int scores[5]比单独定义5个变量更高效 2. 核心优势： - 批量存储：一次性创建多个同类型变量，无需逐个定义 - 有序访问：通过下标快速定位每个元素，便于循环遍历 - 简化代码：结合循环处理批量数据，减少重复代码 🔹 二、数组的创建与初始化 1. 基本创建格式：数据类型 数组名[数组长度]; - 数据类型：所有元素的统一类型（int、float、char等） - 数组名：符合变量命名规则（如arr、scores、nums） - 数组长度：必须是常量（如5、10），创建后不可修改 - 示例：int arr[10]; // 创建能存储10个整数的数组 2. 三种初始化方式： - 方式1：完全初始化（指定所有元素） int arr[5] = {1, 2, 3, 4, 5}; // 数组元素依次为1、2、3、4、5 - 方式2：部分初始化（剩余元素默认0） int arr[5] = {1, 2}; // 元素为1、2、0、0、0 - 方式3：省略长度（由初始化元素个数决定） int arr[] = {1, 2, 3}; // 数组长度自动为3，元素为1、2、3 🔹 三、数组的访问与核心规则 1. 访问方式：通过**下标（索引）** 访问，格式：数组名[下标] - 下标范围：从0开始，到"数组长度-1"结束（闭区间） - 示例：int arr[5] = {10, 20, 30, 40, 50}; arr[0] = 10（第一个元素）、arr[3] = 40（第四个元素）、arr[4] = 50（第五个元素） 2. 三大核心规则（必记）： - 规则1：长度固定——数组创建时必须指定长度（或通过初始化推导），创建后无法修改 - 规则2：下标从0开始——最容易出错的点，避免出现arr[5]访问长度为5的数组（下标最大为4） - 规则3：类型统一——所有元素必须是同种类型，不能混合存储int和float 3. 数组使用基本模板（通用流程）： - 步骤1：输入数据长度（如n） - 步骤2：创建数组（如int arr[n]; 注意：部分编译器需用常量长度，可先定义const int n=5） - 步骤3：动态输入——用for循环遍历数组，通过cin输入每个元素 - 步骤4：动态输出——用for循环遍历数组，通过cout输出每个元素 - 模板代码示例： const int n = 5; int arr[n]; // 输入 for(从0开始，到n 结束，增加数值){ cin >> arr[i]; } // 输出 for(从0开始，到n 结束，增加数值){ // } 作业练习网址： https://code.xdf.cn/freeIde?type=1（或者离线版DEV-C++） 完成后发班级群打卡
