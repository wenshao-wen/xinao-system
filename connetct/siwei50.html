【C++---50字符数组】🌈🌈 本节课重难点来了🌻🌻 ✅ 字符数组，用来存储一串字符，能够区分字符的概念和字符数组的概念。 📝 ✅ 字符数组的创建 ，注意给定字符数组设置长度，区分输入是否包含空格，包含空格如何获取长度，不包含空格如何获取长度！ 📝 ✅ 字符数组的存储和访问 ，常用的字符数组的长度获取！📝 📚📚 重要的知识点梳理 📚📚 ✅① 字符数组的输入（不包含空格 cin , 包含空格 cin.getline()）✅ - cin输入：仅读取到第一个空白字符（空格、回车等）为止 - cin.getline()函数：可读取包含空格的完整字符串 - 使用场景：cin适合单词输入，cin.getline()适合句子输入 - 参数设置：cin.getline(array, size)需指定数组和最大长度 - 注意事项：预留'\0'终止符空间，避免数组越界 ✅② 计算字符数组的实际长度（strlen()）✅ - strlen()函数：返回字符数组中字符的实际数量 - 不包括：字符串末尾的'\0'终止符 - 需要头文件：#include - 返回类型：size_t类型，通常为unsigned int - 实际应用：常用于循环遍历字符数组的每个字符 ✅③ 字母的大小写判断和转换 ✅ - 判断函数：isupper(), islower(), isalpha() - 转换函数：toupper(), tolower() - 需要头文件：#include - 适用范围：仅对字母字符有效 - 实际应用：文本处理、密码验证等场景 📖 核心知识点总结 & 易错点梳理 📖 🔹 字符与字符数组的区别： - 字符变量：char c = 'A'; 存储单个字符 - 字符数组：char str[10]; 存储多个字符序列 - 终止符：字符数组以'\0'结尾，字符变量无此概念 - 访问方式：字符变量直接访问，字符数组需索引访问 🔹 字符数组的创建与初始化： - 静态声明：char arr[100]; 需指定大小 - 初始化：char arr[] = "hello"; 自动计算长度 - 字符逐个赋值：arr[0]='h', arr[1]='e', etc. - 默认终止：字符串字面量自动添加'\0'终止符 🔹 输入方法对比： - cin：读取单词，遇到空格停止，适合单个词汇 - cin.getline()：读取整行，包括空格，适合句子 - gets()：不推荐使用，存在缓冲区溢出风险 - scanf()：格式化输入，但安全性不如cin 🔹 长度获取方法： - strlen()：获取实际字符数（不包括'\0'） - sizeof()：获取数组总字节数（包括'\0'） - 循环计数：手动遍历直到遇到'\0' - 有效长度：strlen()返回的是有效字符数 🔹 字符处理函数： - isupper(c)：判断字符是否为大写字母 - islower(c)：判断字符是否为小写字母 - isalpha(c)：判断字符是否为字母 - toupper(c)：将字母转为大写 - tolower(c)：将字母转为小写 🔹 常见易错点： 1. 数组越界：未考虑'\0'终止符导致空间不足 2. 长度混淆：分不清sizeof()和strlen()的区别 3. 输入安全：使用不安全的输入函数 4. 初始化遗漏：未正确初始化字符数组 作业练习网址：https://code.xdf.cn/freeIde?type=1

字符数组操作示例详解

📝 字符数组声明：char str[100]; 或 char str[] = "hello";

📥 字符串输入：cin >> str; (不含空格) 或 cin.getline(str, 100); (含空格)

📏 获取长度：strlen(str) 返回字符串实际长度（不包括\0）

🔄 大小写转换：toupper(c) 转大写，tolower(c) 转小写

🔍 字符判断：isalpha(c) 判断是否为字母，isupper(c) 判断是否为大写

📍 字符访问：str[i] 访问第i个字符，从0开始
