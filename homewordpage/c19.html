分支语句的选择

  • 单分支： if 语句
    特点：​​只有一个条件判断​​，如果条件成立（True），则执行对应的代码块
  • 双分支： if -else 语句
    有两个可能的执行路径​​：
    如果条件成立（True），执行 ​​if代码块​​；
    如果条件不成立（False），执行 ​​else代码块​​。
    ​​特点​​：​​“如果满足条件，就做 A；否则，做 B”​​。
  • 多分支： if -else if --else if ... 语句
    特点： 有多个条件判断​​，程序会 ​​从上到下依次检查​​，​​第一个满足的条件​​ 执行对应的代码块，​​后面的条件不再检查​​。
    如果 ​​所有条件都不满足​​，则执行 ​​else代码块​​（可选）。
    ​​特点​​：​​“如果满足条件1，就做 A；否则，如果满足条件2，就做 B；……；否则，做 C”​​。

重点难点解析

分支选择策略

  • 分支的选择：
    1个判断判断单分支；
    2个判断是双分支
    多个判断选择其中一种 多分支
  • 分支的选择 ：
    ​​单分支（If）​​：​​“如果满足条件，就做某事”​​（可能不做）。
    ​​双分支（If-Else）​​：​​“如果满足条件，就做 A；否则，做 B”​​（必做其一）。
    ​​多分支（If-Elif-Else）​​：​​“按优先级判断，第一个满足的条件执行”​​（只执行一个）。
    ​​分支语句是编程的基础，掌握它们才能写出灵活的逻辑！​​ 🚀
  • 多分支判断 ：
    if-elif-else是编程中用于多条件判断的语句结构，适用于多个互斥选项的情况。其核心逻辑是：
    if条件：首先检查第一个条件，若为 True，则执行对应代码块，并跳过后续所有判断。
    elif条件（else if 的缩写）：若 if不成立，依次检查后续的 elif条件，一旦某个 elif为 True，执行其代码块并终止判断。
    else：若所有 if和 elif均不成立，则执行 else代码块（可选，用于兜底默认情况）。
    特点：
    互斥性：只有第一个满足的条件会被执行，后续条件不再判断。
    灵活性：可包含任意数量的 elif分支，适应复杂逻辑。
    必选/可选：else非必需，但通常用于处理未覆盖的默认情况。

示例1：小杨的饮料1

【题目】小杨看了同一种饮料，发现每种饮料也有不同的大小瓶，现在他需要根据家里的人数进行可乐大小容量的选择，需要输入对应的人数，1个人输出小瓶，2个人，输出中瓶，如果是3个人以上，输出购买大瓶
【思路】 单价：橙汁4.5元/瓶，可乐2.6元/瓶，牛奶3.5元/瓶。
输入：依次输入三种饮料的购买数量（整数）。
计算：总费用 = 橙汁数量×4.5 + 可乐数量×2.6 + 牛奶数量×3.5。
输出：直接求和并输出结果（可保留两位小数）。
关键点：单价固定，总费用为各饮料单价与数量的乘积之和，无需考虑容量（350ml不影响计算）。直接按公式计算即可。

【关键代码】 多分支语句选择 if ---else if
【说明】 3. 使用数学公式： 总价 = 单价 * 数量

示例3：小杨的饮料3

【题目】小杨家里有3个人，爸爸妈妈和小杨，现在他准备购买3种不同的饮料。依次输出每一种可乐的购买数量，小瓶价格是2.6元，中瓶可乐的价格是3.7元，大瓶可乐的价格是6.3元，但是每一种饮料的购买数量不同，所以总价格也不同，请你按照每一种价格的付钱按照从高到低进行排序！。
【思路】
题目要求：小杨家有3口人，购买可乐（小瓶、中瓶、大瓶），但每种瓶子的购买数量可能不同，需要计算总价格并按从高到低排序。
已知条件：
小瓶：2.6元/瓶
中瓶：3.7元/瓶
大瓶：6.3元/瓶
输入：依次输入 小瓶、中瓶、大瓶的购买数量（3个整数）。
计算：
计算每种瓶子的总价：
小瓶总价 = 2.6 × 小瓶数量
中瓶总价 = 3.7 × 中瓶数量
大瓶总价 = 6.3 × 大瓶数量
汇总所有瓶子的价格，并 按从高到低排序（降序排列）。
输出：排序后的价格列表（从最贵到最便宜）。
关键点：
先计算 每种瓶子的总价（单价 × 数量）。
再 对3个总价进行降序排序（如 [大瓶总价, 中瓶总价, 小瓶总价]或任意顺序，只要从高到低）。
无需考虑饮料种类，只按 价格高低排序。
【关键代码】 if -else if
【说明】 多分支语句
